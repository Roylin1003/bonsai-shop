# 盆栽小舖 Bonsai Shop

*A collaborative project by roylin1003 and Claude.*

看葉子，不看數字：拖水壺、拖盆子，慢慢把它們養活。有水壺、肥料、剪刀、換盆、蟠紮，通關解鎖盆景台。
純 HTML5 單檔，不需安裝、不需伺服器。

**▶ 立即遊玩**：https://bonsai-shop.roynexus.com/

> 目前為 **ALPHA 測試版**，版面與數值仍在調整中。歡迎回報手感問題。

## 操作

拖曳水壺、盆子到植物上；手機與桌機皆可（觸控／滑鼠）。標題畫面「新遊戲（盆景台已解鎖）」可直接進盆景台。
